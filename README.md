# 🎤 AI Mock Interview System

An AI powered Mock Interview System built with Streamlit and Groq API.

## Features
- Choose from 6 job roles including TCS NQT, Software Engineer, AI/ML Engineer
- AI asks 5 interview questions one by one
- Scores each answer out of 10
- Gives final feedback report with overall score
- Shows strengths and areas to improve
- Final verdict - Ready / Almost Ready / Need More Preparation

## Tech Used
- Python
- Streamlit
- Groq API
- Llama 3.3 model

## How to Run
pip install streamlit groq
streamlit run app.py

## Job Roles Available
- TCS NQT - Fresher
- Software Engineer
- Data Analyst
- AI/ML Engineer
- Web Developer
- QA Tester
